## Open items

1. **Tab frame order (lead, lane C1).** The vanilla files give the default tab `frame = 1` (`countrytechnologyview.gui`: `research_slots_tab` frame 1, `facilities_tab` frame 2) and draw frame 1 lit, so frame 1 is the selected tab. The C1 tab rule (`lib/ui_plan.mjs` `isTab`, 46 rows in many windows) puts the plain `tab` cell in frame 1 and `tab_selected` in frame 2, which is why the before render highlights "Experimental Facilities". This lane's own tabs use frame 1 selected; the C1 rows (the doctrine tabs and every other window's tabs) still have it reversed. One-line fix in the rule, across lanes; the Linux run should confirm.
2. **Cells of the right class.** A follow-up `ui-focus` sheet with a light glow, a mid rubric band and a light gilt band would build the remaining pending focus textures; `research_line_bg` wants a wider line plate (check 16 1.06).
3. **Check 17 on connector strips.** The plan fills every frame of a focus link or tech line strip with one cell, so a strip's state frames are identical (34 such findings before, 102 now that the links build). The frames should carry the states (grey for not available, bronze, gilt for done); that needs per-frame cells and the vanilla frame meanings, a plan change for the lead.
4. **Focus title.** `national_focus_title` is filled by the engine; check on Linux that `hoi_24header` fits the longest tree name in 500 px.
