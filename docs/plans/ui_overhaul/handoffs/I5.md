## Resume

1. Check `tools/content/data/idea_art_cells.json`: the first sheet with status `planned` in production order is the next to generate.
2. Write its jobs: `node tools/content/modules/idea_art.mjs jobs <sheet>... "<art store>/jobs/i5/<name>.json"`. Runner: `GPTIMAGE_MODEL=gpt-6-luna IMAGEGEN_CONCURRENCY=3 node tools/content/imagegen.mjs <jobs.json>`. If it prints "holds the image route", wait a few minutes and retry in the background; never kill another process.
3. Cut and review: `node tools/content/modules/idea_art.mjs preview <sheet>` writes 1x and 3x contact sheets to `<art store>/processed/idea/`. Review every plate against its subject; regenerate failures with a subject change if needed. A plate that reads as a cross, a crossed object, a face, text or a modern object is a failure.
4. Accept: append the generation line (from `jobs/i5/provenance.jsonl`) and a review line (`accepted: true`, `reviewer: agent`, sha256 of the raw bytes) to both `art/source/provenance.jsonl` (mod) and `<art store>/jobs/provenance.jsonl`, append only. Set the sheet's `status` to `accepted` in the cell map. A scratch script for this step is at `<scratchpad>/i5/accept.mjs`; it takes sheet names as arguments.
5. Add subjects for every new picture key to `tools/content/data/idea_art_subjects.json` before generating its jobs.
