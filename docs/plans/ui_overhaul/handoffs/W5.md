## Renders and metrics

Renders were made with `hoi4.gui_render` (runtime v461) from a UI-only staged tree: the C1 reskin, the C2 text colours and this module, with the installed mod's localisation and event pictures. A full build could not be used at the time, because the Yeldenne retirement and then a story-wiring check stopped `build.mjs` in another lane's files. The "before" tree is the same build without this module. The scenarios use real ZIN text: `zin_regional_seite_islands.1.t` (45 characters, the longest title) over `zin_lore.220.d` (699 characters, the longest body), with six options including the longest (`zin_volgan.12.a`, 81 characters), and `zin_eindil.82` (five options). They also use real pictures (`GFX_zin_evt_chronicle`, `GFX_zin_news_coronation`), the engine's growth emulated through `midsection.height`, `bottom_Window.y` and `Description.height`, and a tooltip preview on `sort_value_button`. Each window renders at 1280 × 720, 1920 × 1080, 2560 × 1440 and 1920 × 1080 at UI scale 1.25, plus hover and full-list states. In `renders/W5/before/` and `after/` there is one contact sheet per window and `metrics.json`; side-by-side crops are in `compare_events.png`, `compare_menus.png` and `compare_settings.png`.

Diagnostics: the pause menu's 15 `CONFLICTING_CLICK_REGIONS` are gone (0 after); `NEAR_CENTRE_OFFSET` and `VISIBLE_OVERLAP` of the event window are gone. The event, news and Gathering Dark windows report `CHILD_OUTSIDE_CLIPPED_PARENT`/`ACCIDENTAL_CLIPPING` only for the vanilla list grid and the news picture, which deliberately hangs out of the 40 px `top_Window` with `clipping = no`. The windows fit 1280 × 720: the tallest case (news, 699-character body, three options) runs from y 56 to 696.

Earlier passes found and fixed: (1) `garamond_16` is not a bitmap font in 1.19.3 (only `garamond_12` and `garamond_14` exist), so the body fell back to the default font; the bodies now use the C2 alias `hoi4_typewriter16`. (2) `hoi_24header` small caps cut the 45-character title; event titles now use `hoi4_typewriter22_inverted`. (3) The news page covered its picture. (4) The renderer ignores `borderSize`, so margins are positions. (5) The first options row texture was too busy behind labels (ground 0.07); the row is now the plain iron cell. (6) The tooltip rim was cut off by the vanilla alpha.

## Open items

1. **Theme of the pause menu.** Design system §7 and `data/ui/chrome_themes.json` map `ingamemenu` to the Banner Hall (lead mapping). Lane W5 followed the lead's instruction that menus are neutral. The lead should update §7 and `windowThemes`/`guiRules`, or tell this lane to switch to Banner Hall (a data change in `dialogs.json`).
2. **Font roles.** `design_system.json` `fontRoles.reading` lists `garamond_16`, which does not exist as a bitmap font in 1.19.3. The working faces are the C2 aliases `hoi4_typewriter16` (Garamond 16, ink) and `hoi4_typewriter22_inverted` (Garamond 24, light). They should be added to the role table (reading and event title), otherwise check 18 would flag them once it covers overrides.
3. **One event body uses `§Y`.** `zin_east.31.d` uses `§Y` on the vellum page, where `hoi4_typewriter16` keeps its vanilla per-font gold for paper (238, 201, 35). That is readable but weak; the text owner may prefer `§b`-safe emphasis.
4. **Unused event rows.** The `ui-events` and `ui-news` rows (clipboard pieces cut to the vanilla clipboard silhouette) can be set to `U` with a reason "replaced by the ZIN event window sprites (lane W5)" in the next plan regeneration. They are not drawn by any reachable window any more.
5. **Homepage link.** Spec 06 §5 proposes pointing `homepage_button` at ZIN's repository; not done (spec Draft; behaviour change).
6. **`tools/package.json`.** The test script contains `content/aoaz_bar.test.mjscontent/cultures.test.mjs` (a missing space, from another lane's edit), and `content/ui_dialogs.test.mjs` still needs adding.
