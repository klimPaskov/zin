# Port to Hearts of Iron IV 1.19.4.1

Owner decision K73 (`docs/specs/INTEGRATION_DECISIONS.md`): Steam updated the game on 1 November 2026 to "Operation Postern v1.19.4.1.99a5 (f584)", and ZIN targets 1.19.4.1 from now on.
This note records what the update changed that touches ZIN, what the port changed, and what only the isolated Linux run can confirm.

## Method

The installed Windows game (`C:/Program Files (x86)/Steam/steamapps/common/Hearts of Iron IV`, `rawVersion` 1.19.4.1) is the authority.
The isolated Linux harness install (`/home/klim/games/hoi4`, read only, `rawVersion` 1.19.3.0 at the time of the port) served as the 1.19.3 baseline for byte diffs of the documentation, defines, script constants, English localisation, the overridden `.gui` files and the vanilla file lists.
The changelog in the install no longer carries patch notes, so nothing here relies on forum notes.

## What changed in the game that matters to ZIN

### Engine documentation

- `documentation/effects_documentation.md`, `triggers_documentation.md`, `modifiers_documentation.md`, `script_concept_documentation.md`, `dynamic_variables_documentation.md`, `loc_objects_documentation.md` and the rest of `documentation/` are byte-identical to 1.19.3, except `console_commands_documentation.md`, which drops the release-unavailable `debug_types`.
- The engine-forms checks (`tools/content/checks/engine_forms.mjs`) and the effect and trigger vocabularies of the event and focus checks therefore stand unchanged.
- `common/ai_strategy/_documentation.md` documents a new AI strategy type, `stockpile_fuel` (`start_below`, `stop_above`), which makes the AI stand down attack plans until its fuel recovers. It reads no `state_trigger`, so `STATE_TRIGGER_STRATEGIES` stays as it is. It is a new tool for the ZIN AI work, not a breaking change.
- Every other `_documentation.md` under `common/`, `gfx/`, `interface/`, `map/`, `history/` and `events/` is unchanged.

### Defines

`common/defines/00_defines.lua` and `00_graphics.lua` only gain defines and change one default; nothing ZIN overrides was removed or renamed, so `data/defines.json` still names only defines the game holds.

- New: `VOLUNTEERS_RECALL_DAYS_PER_UNIT`, `SEND_VOLUNTEERS_AGAIN_COOLDOWN`, `RECALL_VOLUNTEERS_AFTER_ARRIVAL_COOLDOWN` (volunteers can now be recalled), `MAX_CASUALTY_TRICKLEBACK`, the `AUTO_IMPORT_*` group (automatic importing of strategic resources for the player), `MOBILIZATION_RATIO_REQUIRED_TO_RAISE_MOBILIZATION_LAW` and `LENDLEASE_TO_CAPITULATED_DESIRE_PENALTY` (AI), `AUTO_DIPLOMACY_RESPONSE_ITEM_ALPHA`, `FOCUS_MINIMAP_SCALE`, `FOCUS_MINIMAP_MIN_SIZE` and the `INFO_WINDOW_*` placement defines.
- Changed: `REQUEST_AUTOMATION_AUTO_ACCEPT_PURCHASE_DEFAULT` is now `true`, so by default a player accepts purchase requests at the international market (the Great Fairs of the institutions spec) automatically.

### Script constants and vanilla script

- `common/script_constants/country_groups.txt` adds `HBC` to a group and `state_groups.txt` adds Bulgarian sea-coast state groups; ZIN replaces `common/script_constants`, so neither loads.
- The new vanilla script files (`common/ai_strategy/BRA.txt`, `common/decisions/TIB.txt`, `common/peace_conference/ai_peace/FRA.txt`, `common/scripted_guis/MTG_naval_treaty_scripted_gui.txt`, `common/scripted_guis/RAJ_GOE_partition_scripted_gui.txt`, `common/scripted_triggers/postwar_scripted_triggers.txt`) all sit in folders ZIN replaces, so none of them loads. No new vanilla folder appeared, so the folder dispositions (`data/vanilla/dispositions.json`) stand.
- `common/country_tags`, `common/country_tag_aliases` and `history/countries` are unchanged; the four new flag files are cosmetic `samanid_empire_tag_*` variants, and every three-letter word in the new script files is already in `data/vanilla/country_tags.json`.

### Interface files ZIN overrides

Every override module builds its file from the installed vanilla `.gui` at build time and swaps sprites by sprite name, so a changed vanilla file is followed automatically and every engine-named element is kept.
Seven files on the closed override list (`OVERRIDE_FILES` in `tools/content/lib/ui_plan.mjs`) changed:

- `interface/nationalfocusview.gui` (lane W3, `ui_research.mjs`): a focus-tree mini-map (`mini_map_clip`, `mini_map`, `minimap_border`, `handle`, camera quads; sprites `GFX_focus_minimap_bg`, `GFX_focus_minimap_border`, `GFX_minimap_quad_pixel`, `GFX_minimap_handle_default`), hidden `cycle_focus_next` and `cycle_focus_prev` buttons on Ctrl+Tab and Ctrl+Shift+Tab, and the focus shortcut bookmark is now a full-size button `shortcut_button` with `GFX_focus_shortcut_button` instead of a background.
- `interface/countrytechtreeview.gui` (`technologies.mjs` through `lib/tech_tree_gui.mjs`): `cycle_tab_next` and `cycle_tab_prev` buttons, a fade removed, and a details window moved with `click_to_front`.
- `interface/countrydiplomacyview.gui` (lane W2, `ui_chancery.mjs`): the automatic-response editor (`actions_title`, `edit_auto_response`, `response_icon`), a whole `recall_volunteers` window, and `acceptance` icons on the request entries.
- `interface/countrydecisionview.gui` (lane W2): two positions moved.
- `interface/countryintelligenceagencyview.gui` (lane W4, `ui_military.mjs`): the empty-operations container is gone, a `show_unavailable_operations` checkbox and label are new, a `queue_badge` shows the upgrade queue, and a tooltip key is renamed to `CANCEL_AGENCY_UPGRADE_BUTTON_TOOLTIP`.
- `interface/settings.gui` (lane W5, `ui_dialogs.mjs`): new `color_after_overlord` and `wasd_camera_active` options and narrower option labels.
- `interface/career_profile/playthrough_overview_window.gui`: listed as an override but written by no module, so nothing to follow.

The other overridden files (`eventwindow.gui`, `ingamemenu.gui`, `worldtensionwindowpopup.gui`, `frontendmainview.gui`, `frontendgamesetupview.gui`, `countrypoliticsview.gui`, `peaceconferencewindow.gui`, `popupwindow.gui`, `countrytechnologyview.gui`, `countryintelledger.gui`) and the overridden `.gfx` files are unchanged.
No swap names an element or sprite the update removed.

### Interface inventory

47 interface files changed, one was removed (`interface/international_market/requestautomationoptionswindow.gui`) and two are new (`MTG_naval_treaty_scripted_gui.gui`, `RAJ_GOE_partition_scripted_gui.gui`).
The inventory grows from 31,561 to 31,611 sprites.
Textures that changed in place: `global_diplorequest_icons.dds` (19 to 21 frames), `cont_focus_check_icon_small.dds` (2 to 3 frames), `ladder_background.dds` and `playthrough_stats_bg.dds`.
New textures include `alerts/global_alert_counter.dds`, `alerts/global_alert_stack.dds` (alert stacking), `buttons/advisor_category_filter_button.dds`, `privacy_reveal_eye.dds` and `repair_order_entry_bg.dds`.

### Localisation

In the 85 English files the text sweep reads, 232 keys are new, 3 are gone (`CLICK_DETAILS`, `DIPLOMACY_REQUEST_CLICKS`, `TRADE_CIV_FACTORIES_USED`), 26 changed their placeholders and 365 changed their wording.
Most wording changes are a house-style pass on click hints (`§GClick to ...§!` became `§GClick§! to ...`, `Shift + Click` became `Shift+Click`, final full stops dropped), which ZIN's own wording does not follow and need not.
The changes in meaning: focus search and filter now use Ctrl+Tab, Ctrl+F, Shift+Enter and Alt+Enter; the military industrial organisation trait queue is filled with Click and emptied with Right-click instead of Shift + Click; a new Alt + Right-click on the delete-order button deletes only airborne and naval invasion orders; `TRIGGER_IS_PUPPET` and `TRIGGER_IS_NOT_PUPPET` no longer take `$COUNTRY$`; the same-ideology opinion modifiers now describe Improve Relations; volunteers can be recalled; automatic importing, automatic diplomatic responses and stacked diplomatic requests are new.
A new file, `keybinds_l_english.yml`, names the keys the engine prints in `$KEYS:...$` hints.

## What the port changed

The row for the removed `TRADE_CIV_FACTORIES_USED` (`trade.json`) and the neutral entry for the removed `DIPLOMACY_REQUEST_CLICKS` (`alerts.json`) are gone.
- New keys the gated families must write, in ZIN wording: `alert_no_research_shift_click` (`alerts.more.json`); `alert_lack_of_resources_auto_import` and the ten `DIPLOMACY_REQUEST_*` click and stack hints (`alerts.json`, with `DIPLOMACY_REQUEST_STACK_FROM_COUNTRY`, a bare `$COUNTRY|Y$`, added to the neutral list); `UNITS_VIEW_BTN_DELETE_ORDER_ALT_RIGHT_CLICK` and `TIME_UNTIL_RECALL` (`core.military.json`); `MODIFIER_OPINION_GAIN_MONTHLY_SAME_IDEOLOGY_DESC` and `_FACTOR_DESC` (`tooltips.modifiers.json`); `TRIGGER_IS_NOT_PUPPET` (`tooltips.realms.json`). - `INDUSTRIAL_ORG_TRAIT_TOOLTIP_ADD_TO_QUEUE_UNLOCK` and `INDUSTRIAL_ORG_TRAIT_TOOLTIP_REMOVE_FROM_QUEUE_UNLOCK` (`production.guilds.json`) name the new controls (Click, Right-click); their placeholders did not change, so the sweep would not have caught them.
- Rows other modules own, whose vanilla placeholders changed: `DIPLOMACY_INCOMING_LEND_LEASE_DEAL_DESC` gains `$ACCEPTANCE$` (`data/diplomacy_text_actions.json`); `TRADE_CAN_TRADE_TOOLTIP` gains `$TRADED|H$` (`data/economy_text_ui.json`); `INDUSTRIAL_CAPACITY_DESC` gains the great-power sentence the game added, without naming the vanilla numbers because ZIN changes `MIN_MAJOR_COUNTRIES` at a later stage, and `alert_naval_convoy_raiding_results_delayed_click` follows the new colour codes (`data/economy_text_core.json`). No ZIN module writes a key the game removed.
- `families.json`: `game` is `1.19.4.1` (the scan's X1 check compares it with `launcher-settings.json`), and the core family sweeps `keybinds` as well (the file otherwise fell to the catch-all content row). `glossary.json` and `banned_words.json` record `game` 1.19.4.1.
- With the installed game the sweep writes 4,301 entries, the swept families hold 39,346 keys (39,038 on 1.19.3), and no family in the `banned` or `strict` gate shows installed banned text.

### Descriptor

`descriptorText` in `tools/content/modules/vanilla_removal.mjs` writes `supported_version="1.19.*"` (constant `SUPPORTED_VERSION`), and test C2 in `tools/content/vanilla.test.mjs` asserts it.

## Verification

Full build and suite (`verify.sh v14`, 1 November 2026, shared checkout with lanes in flight):

- The text sweep builds (it aborted on 13 rows before the port), and the text scan passes with no failing finding; every family in the `banned` and `strict` gates shows no installed banned text.
- `ui_reskin.mjs validate` reports no problem; the regenerated inventory is byte-identical across two runs; the text sweep, reskin and inventory tests that read the real game pass on 1.19.4.1.
- The build stops at its last step, the asset check, on errors of the event-art lane only: the Eindil beat pictures `zin_evt_beat_*_2` (undefined sprites in one run, byte-identical pairs in the next, while that lane generates them) and the picture caps of `GFX_zin_evt_grave_muster` and `GFX_zin_evt_gala_court`. The one asset error the port caused (the new alert counter cut from the same socket cell as `small_box1.dds`) is declared as an alias in `data/assets/uniqueness.json`.
- Suite: 1,752 pass, 21 fail, 2 skipped. Every failure belongs to a lane in flight or follows from the missing staged tree: the build-dependent tests (roster, ideologies, calendar and reckoning, defines, flags, cultures, sprites, determinism, `vanilla.test.mjs`, which therefore did not yet run the new `supported_version` assertion), the event catalogue and picture keys (presentation and event-art lane: `presentation-cells.json`, `presentation.mjs`, the `art/source/events/beat_*` pictures), and the roster migration and state assignment dry runs (roster lane: `roster_state_assignment.mjs`, `data/world/state_assignment.json`).
