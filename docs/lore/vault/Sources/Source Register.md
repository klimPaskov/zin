## Editorial priority

A prior source mentioned Eindil's 100,000-year magical sleep. Later conversations floated a roughly 5,000-year life. The creator has since withdrawn the 5,000-year cap, so **Eindil and Afrit have approximately the same age with no numerical limit presently selected**. The canonical Second Age is 2,133 years, and the Third Age lasts at least 1,200 years. The proposed 128-year Third Age is obsolete.

Assistant-proposed names include **Aurevan** for Afrit's public name, **Harion** for a restored king, **Sevrin** for the Abyss thief, **Merovan** for a chancellor, and proposed battle/organization titles. See [[Fourth Age Canon Register]] and [[Names and Retcons]].
